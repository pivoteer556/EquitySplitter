Project

EquitySplitter

Python, FastAPI, PostgreSQL, Azure

Try the early, barebones live demo. The repository shows the full build and deploy pipeline behind it.

  • Architected a spec-driven API for shared mortgage equity, with the equity ledger as the single source of truth. The first version was built with Claude as product owner and Codex as coder.
  • Then ran a multi-agent build-and-review workflow over the repository. It replaced salted SHA-256 password hashing with argon2id, added rate limiting and a signed-token invitation flow, grew the test suite from 5 to 260+, and cleared known dependency vulnerabilities.
  • Locked down account creation: bootstrapping an institution requires a signed-in platform admin plus a setup token, and officers and owners are issued one-time activation links so no one else ever chooses their password. Officers must enrol an authenticator at first sign-in, and every sign-in then needs a one-time code that can’t be replayed. Single-use recovery codes cover a lost device and are stored only as keyed hashes.
  • Containerized the API and defined its Azure footprint in Terraform: Container Apps, Container Registry, PostgreSQL, Key Vault, and a GitHub identity for deployment.
  • Built the delivery pipeline. CI runs linting, type checks, dependency scanning, tests on two Python versions, migrations against PostgreSQL, Angular specs, an end-to-end browser suite, and Docker and Terraform validation. After it passes, the exact validated commit deploys to Azure with no stored cloud credentials, and the deploy fails if the new revision doesn’t answer its health check.
